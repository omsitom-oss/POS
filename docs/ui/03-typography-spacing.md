# Typography and spacing

Typography, spacing, control heights, radii, shadows, and transitions are centralized in `frontend/src/styles/system.css`. Prefer shared tokens and component rules over repeated values in feature CSS. Typical text is 15–16px, table text 14–16px, labels 14–15px, and helper text at least 13px. Page titles are generally 28–32px. Arabic uses generous line height.

Inputs and primary actions are generally 40–44px high. Tables and cards remain compact but comfortable for long daily use. Use logical inline/block spacing so dimensions and alignment work in RTL and LTR.
