# Elite POS React UI

This is the browser-based React + TypeScript interface. Shared layout and visual components live under `src/layouts` and `src/components`; centralized styles are in `src/styles/system.css`. The Design Lab uses fake data only.

See [the application README](../README.md) for startup instructions and [the architecture notes](../docs/architecture.md) for provider, RTL, and design-system decisions.
